# Proyectos

Colección de proyectos y ejemplos web desarrollados por AndresStw.

Incluye sitios estáticos y pequeños proyectos front-end creados principalmente con HTML y CSS, con algunos ejemplos en JavaScript y ejercicios puntuales en Java. Está pensado como portafolio y material para aprender o experimentar con conceptos y técnicas web.

Si necesitas que añada más detalles (por ejemplo, una lista de proyectos o instrucciones de ejecución), dímelo y lo amplío.
